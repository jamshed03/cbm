# ContentBlockManager (cbm)

TYPO3 v14 extension with tooling around [Content Blocks](https://github.com/FriendsOfTYPO3/content-blocks).

## Roadmap

1. Migrate labels from `config.yaml` into `language/labels.xlf` (and remove them from the YAML)
2. Generate backend previews
3. Backend module to create, edit and delete Content Blocks
